# Configuración de agentes para Voto UTN

Copiar el contenido de esta carpeta en la raíz del repositorio.

## Archivos

- `AGENTS.md`: instrucciones para Codex.
- `docs/prompt_maestro.md`: especificación completa.
- `docs/decisiones_funcionales.md`: decisiones confirmadas.
- `docs/modelo_dominio.md`: modelo objetivo.
- `docs/plan_implementacion.md`: plan por etapas.
- `.github/copilot-instructions.md`: instrucciones generales de Copilot.
- `.github/instructions/*.instructions.md`: instrucciones específicas.

## Primer pedido recomendado para Codex

Leé `AGENTS.md` y toda la documentación obligatoria que referencia.

Ejecutá únicamente la Etapa 0 del plan de implementación.

- inspeccioná todo el repositorio;
- no implementes todavía el modelo objetivo;
- no modifiques la funcionalidad del QR;
- ejecutá las verificaciones disponibles;
- identificá inconsistencias entre código y documentación;
- proponé el modelo y la estrategia de migración;
- no avances a la Etapa 1.

Seguí exactamente el formato de primera respuesta definido en `docs/prompt_maestro.md`.
